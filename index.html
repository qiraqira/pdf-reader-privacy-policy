Privacy Policy — PDF Reader

Last updated: 16 August 2026

PDF Reader is an offline document viewer. This app does not collect, store, transmit, or share any personal data, usage data, or analytics of any kind.

What the app does

  • Opens and displays PDF files you choose, entirely on your device.
  • Renders pages, lets you search text, select/copy text, and zoom/pan, all locally.
  • Optionally saves a copy of the opened file, or exports a page as an image, to a location you pick via the Android system file picker / share sheet.

What the app does NOT do

  • It does not use the internet. There is no network code in the app at all.
  • It does not use analytics, crash reporting, or advertising SDKs.
  • It does not collect or transmit your files, file names, or any content you view.
  • It does not require an account, login, or any personal information.

Permissions used

PermissionWhy
Storage (Android ≤ 9 / API 28 only)Needed only on old Android versions to save an exported image to the gallery. Not required on Android 10+ (scoped storage handles this instead).

No other permissions are requested. The app only accesses a PDF file after you explicitly pick it via the system "Open" dialog, or when you open a PDF from another app ("Open with…").

Children's privacy

The app does not knowingly collect any data from anyone, including children, because it does not collect data at all.

Changes to this policy

If this app ever starts collecting data in the future, this policy will be updated first, and the update will be reflected in the Play Store listing.

Политика конфиденциальности — PDF Reader

Обновлено: 16 августа 2026

PDF Reader — это оффлайн-приложение для просмотра документов. Приложение не собирает, не хранит, не передаёт и не делится никакими персональными данными, данными об использовании или аналитикой.

Что делает приложение

  • Открывает и показывает выбранные вами PDF-файлы — полностью на вашем устройстве.
  • Отрисовывает страницы, позволяет искать текст, выделять/копировать текст, масштабировать — всё локально.
  • По вашему запросу может сохранить копию открытого файла или экспортировать страницу как изображение — в место, которое вы сами выбираете через системный диалог сохранения.

Чего приложение НЕ делает

  • Не использует интернет — в приложении вообще нет сетевого кода.
  • Не использует аналитику, отчёты о сбоях или рекламные SDK.
  • Не собирает и не передаёт ваши файлы, их названия или содержимое.
  • Не требует аккаунта, входа в систему или каких-либо личных данных.

Используемые разрешения

РазрешениеЗачем
Хранилище (только Android ≤ 9 / API 28)Нужно только на старых версиях Android для сохранения экспортированного изображения в галерею. На Android 10+ не требуется.

Никакие другие разрешения не запрашиваются. Приложение получает доступ к PDF-файлу только после того, как вы явно выбрали его через системный диалог "Открыть", либо когда вы открываете PDF из другого приложения ("Открыть с помощью…").
